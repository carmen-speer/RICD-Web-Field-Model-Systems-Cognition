# Web–Field Model of Cognitive Trait Distributions and Social Evolution

An early-stage working theory applying the mathematics of Recursive
Information–Container Dynamics (RICD), the framework behind
[Tell](https://github.com/carmen-speer/Recursive-Information-Container-Dynamics),
to a second domain: modeling human cognitive traits as regions on a
continuous manifold rather than as discrete types, and deriving from that a
proposed learning-style metric, the Cognitive Trait Manifold Ratio (CMTR).
It has not yet been validated against data.
